# Client — optional playground (not the product)

This React (Vite + Tailwind) UI is a **developer / self-test shell**:

- Paste your own API Key (BYOK)
- Hit `/peel` `/matrix` `/wizard` `/score` against the local Node server
- View quality-gate warnings and PEEL layers

**End-user product = the Skill** at `../skill/SKILL.md`, not this UI.

## Run (only if you need the debugger)

```bash
cd ..
# Prefer system npm if user npm is broken:
/usr/local/bin/npm run dev
```

Open http://localhost:5173
